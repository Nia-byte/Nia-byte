## Hi, I am Nia Diale 
I build software from a blank repo to a deployed product that real people use. I've built an AI learning platform that gives developers real-time code feedback with Claude, shipped five production websites for South African businesses, and deployed full-stack apps to Azure. Right now I'm focused on AI-powered apps: LLM integrations, agents that take real actions, and getting them running reliably in the cloud.

- 🔭 I'm currently buidling: **Ask the Aisle**, an AI shopping assistent that finds products, checks specials and plans a R250 dinner from store's real stock and prices.
- 👯 I'm into LLM apps, AI agents that take real actions, RAG and making AI fast, safe and affordableto run everyday.

## Things I've built
 
**[Prog It!](https://github.com/Nia-byte/REPLACE-WITH-REPO)**: a coding practice platform with an AI tutor. You solve LeetCode-style challenges in Python, C# or Java, and Claude gives you hints and feedback on *your* code instead of handing you the answer.
`Python` `Flask` `React` `Claude` `MongoDB` `Docker`
 
**[EasyKanban](https://github.com/Nia-byte/EasyKanban)**: a REST API for running agile projects: boards, tasks, JWT login and analytics like completion rates and who's carrying the team.
`Java 21` `Spring Boot` `MySQL` `Spring Security`
 
**[CMCS](https://github.com/Nia-byte/CMCS-Claim-Management-and-Communication-System)**: a claims system for institutions where each role submits, reviews or approves claims and sees only what it should. Deployed on Azure.
`C#` `ASP.NET Core` `Entity Framework Core` `Azure`
 
**[Zaka](https://github.com/Nia-byte/Personal-Budget-Tracker-App)**: a budgeting app that turns saving into a game, with real-time spending analytics. I built the database and backend with my team.
`Kotlin` `Firebase`
